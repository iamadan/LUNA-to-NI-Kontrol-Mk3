Setup — what has to be true for the DAW button to light
  • Keyboard firmware 2.0 or later. Only then does the Mk3 expose its own DAW port — KONTROL S88 MK3 DAW, or the S61 / S49 spelling of it. Update in Native Access, then power-cycle the keyboard.
  • LUNA 3.1.2 or later. Earlier builds cannot send SysEx out of a MIDI port, and nearly everything the keyboard's screens show is SysEx.
  • Nothing else may hold the keyboard's DAW mode. Komplete Kontrol running as a plugin on a LUNA track is fine — that is what the PLUG-IN button is for — but Komplete Kontrol standalone takes the keyboard for itself. Quit it, or press Release to Komplete Kontrol here.
  • The Port badge should name the DAW port, and DAW mode should read connected (v4). If it says no answer, press Re-handshake.

Connection
Keyboard DAW port: Knob sensitivity:
Knobs 1–8 set volume, shift + knob sets pan, the 4-D encoder selects tracks (left/right) and pages banks (up/down), and MUTE/SOLO act on the track under the button you press. MIDI goes through LUNA itself — there is no helper process to start.

One selection. Moving the selection on the keyboard selects the same track in LUNA, and clicking a track in LUNA moves the keyboard to it. Aux buses and MAIN have no row in the arrangement, so those move the keyboard only.

Record arm. NIHIA has no arm button of its own, so it is on the one spare control: hold SHIFT and push the 4-D encoder in to arm the selected track. Pushing it without SHIFT is left alone, because that is how push-and-turn jogs the playhead.

DAW and PLUG-IN are both live. They are two halves of one connection: DAW shows the mixer, PLUG-IN shows the selected channel's plugin chain, and the keyboard switches between them on its own. On a track carrying Komplete Kontrol, Kontakt, Maschine or Reaktor the plugin pages are handed to the instrument's own NKS screens, while this surface keeps the mixer and the transport.

Compact shrinks this window to a strip that says whether the keyboard is connected, which is all it needs to show while it is doing its job. The surface only runs while the window is open, so this is its resting state; Expand brings the full page back at the size you last left it.

Closing this window no longer stops the surface. The page stays loaded and keeps running, so the keyboard stays live with no window on screen. LUNA reopens the window at launch if it was open when you quit, which is how the surface comes up with LUNA — leave the compact strip open and it is there every time.

Release is the deliberate way out: it drops the connection entirely so Komplete Kontrol can take the keyboard as if LUNA were not running. The DAW button goes dark until you take it back. Since closing the window no longer does this for you, this button (or pressing DAW on the keyboard) is now the way to hand it over.

Reload page re-enters this page from disk. It is only needed after editing the Add On's files: closing and reopening the window no longer reloads it.
